ACME-Models/

A tool that rates AI models on Hugging Face so teams can tell whether a model is trustworthy to build on, scoring licensing, code quality, review coverage, reproducibility and bus factor. I built the bus factor metric, which measures how dependent a project is on a few contributors by analyzing its commit history and contributor activity through the GitHub API.

In phase two, we swapped codebases with another team and had to get up to speed on code we’d never seen before. We moved the tool onto AWS as a web API, and I added a metric that checks how much of a model’s code was actually reviewed before it was merged. I also built the endpoints for looking up an artifact’s cost and deleting artifacts from storage.
