$ cat design-decisions.txt

            
    
                
  • LXC for almost everything. Containers share the host kernel, start faster, use less RAM, and can access the GPU and ZFS datasets through bind mounts. Home Assistant runs as a VM because HAOS is a full operating system and that's the only supported way to run it.
    • 
                
  • Monitor on the Pi, not the server. Uptime Kuma runs on the Raspberry Pi specifically so it can alert if the main server goes down. A monitor that dies with the thing it's watching isn't useful.
    • 
                
  • Zero inbound ports. The building's network doesn't support port forwarding. Everything private goes over Tailscale; Minecraft uses an outbound UDP tunnel. The only traffic that reaches the internet is what I deliberately push out.
    • 
                
  • Static IPs outside DHCP, .lan names everywhere. Services get Pi-hole local DNS records so I can reassign IPs without touching every app's config. Two Pi-holes with sync means DNS keeps working through restarts.
    • 
            

        


        

            
$ cat lessons.txt

            
    
                
  • A ZFS mirror survives a drive failure. It is not a backup — it doesn't protect against deletion, corruption, or the whole server going down. I keep three separate copies of anything I can't re-download.
    • 
                
  • The monitoring server belongs on a separate machine. The first time the main server went down and took Uptime Kuma with it, I moved it to the Pi the same day.
    • 
                
  • A script that prints "finished" even when it failed is worse than no script. I stopped trusting output messages and started checking exit codes.
    • 
                
  • Cron needs full paths. pct silently wasn't found for days because /usr/sbin isn't in cron's PATH. Always redirect output too — errors that go nowhere are impossible to debug.
    • 
                
  • When a dependency changes without warning, you find out at the worst time. A Minecraft update silently dropped the transport protocol my server was using. Now I test in a copy before updating anything production-facing.
